# WinTV

Удобный IPTV-плеер для Windows в духе Televizo / TiviMate.

![icon](WinTV/Assets/wintv.png)

## Возможности

- Плейлисты M3U / M3U8 по ссылке (с кэшем на случай отсутствия сети)
- Группы каналов, поиск, избранное, логотипы
- Программа передач XMLTV (в том числе `.gz`), адрес берётся из `url-tvg` плейлиста
- Архив (catch-up): форматы Flussonic и `?utc=…&lutc=…`, плюс `catchup-source` из плейлиста; режим «авто» подбирает формат сам
- Автопереподключение при обрыве эфира
- Полноэкранный режим, экранная подсказка с текущей передачей
- Тёмная тема, опция «не сохранять историю»

Видео воспроизводится через [LibVLC](https://www.videolan.org/vlc/libvlc.html) с аппаратным декодированием.

## Управление

| Клавиша | Действие |
|---|---|
| Двойной щелчок, F, F11 | Полный экран |
| PgUp / PgDn, ↑ / ↓ в полном экране | Переключить канал |
| Enter в полном экране | Показать список каналов |
| Backspace | Предыдущий канал |
| Цифры | Канал по номеру |
| Колесо мыши, + / − | Громкость |
| M | Без звука |
| Пробел | Пауза |
| G, → | Программа передач |
| ← / → в архиве | Перемотка 30 с (Shift — 5 мин) |
| Esc | Из архива в прямой эфир / выход из полного экрана |
| Ctrl+F | Поиск |
| Ctrl+D, * | Избранное |

## Сборка

Нужен .NET 8 SDK.

```bash
cd WinTV
dotnet build -c Release
```

Готовый `WinTV.exe` будет в `WinTV/bin/Release/net8.0-windows/`. При первом запуске укажите ссылку на свой плейлист в настройках. Настройки хранятся в `%LocalAppData%\WinTV`.
