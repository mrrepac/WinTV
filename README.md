# WinTV

Удобный IPTV-плеер для Windows в духе Televizo / TiviMate.

![icon](WinTV/Assets/wintv.png)

## Возможности

- Несколько плейлистов M3U / M3U8 по ссылке, у каждого своё избранное, скрытые группы, история и (по желанию) своя программа передач; переключение — кнопкой над группами
- Кэш плейлиста на случай отсутствия сети, кэш логотипов на диске (обновляется раз в 7 дней)
- Группы каналов, поиск, избранное, логотипы
- Скрытие групп (например, «для взрослых») с необязательным PIN-кодом; хранится только хеш PIN
- Программа передач XMLTV (в том числе `.gz`), адрес берётся из `url-tvg` плейлиста
- Архив (catch-up): форматы Flussonic и `?utc=…&lutc=…`, плюс `catchup-source` из плейлиста; режим «авто» подбирает формат сам
- Выбор звуковой дорожки и субтитров (клавиши или правый щелчок по видео)
- Автопереподключение при обрыве эфира
- Скрытие боковой панели в оконном режиме для компактного просмотра (кнопка `◀` / `☰`, клавиша `B`)
- Режим «Поверх остальных окон» (кнопка `📌`, правый клик или `Ctrl+T`)
- Внутренний ползунок громкости в боковой панели и во всплывающей панели управления плеером
- Полноэкранный режим: список каналов поверх картинки, курсор прячется сам, экранная подсказка с текущей передачей
- Во время просмотра экран не гаснет и компьютер не засыпает
- Автоматическая проверка обновлений через GitHub Releases при запуске и ручная проверка в настройках с обновлением в один клик
- Тёмная тема, опция «не сохранять историю»

Видео воспроизводится через [LibVLC](https://www.videolan.org/vlc/libvlc.html) с аппаратным декодированием.

## Управление

Горячие клавиши меняются в настройках (Ctrl+,): у каждого действия две ячейки, щёлкните и нажмите сочетание.
По умолчанию:

| Клавиша | Действие |
|---|---|
| F, F11, двойной щелчок | Полный экран |
| B, Ctrl+B | Боковая панель (скрыть / показать) |
| Ctrl+T | Поверх остальных окон (Always on top) |
| Ctrl+F | Поиск канала |
| Ctrl+D, Num * | Избранное |
| G | Программа передач |
| I | Информация о передаче |
| PgUp / PgDn | Предыдущий / следующий канал в списке |
| Backspace | Вернуться к прошлому каналу |
| Пробел | Пауза |
| M | Без звука |
| A | Звуковая дорожка (по кругу) |
| S | Субтитры (по кругу, включая «Выкл») |
| + / −, колесо мыши | Громкость |
| ← / → (Shift — 5 мин) | Перемотка архива на 30 с |
| Ctrl+H | Показать / спрятать скрытые группы (спросит PIN, если задан) |
| Ctrl+R, F5 | Обновить плейлист |
| Ctrl+, | Настройки |

Не настраиваются и работают всегда: стрелки в списках, ↑ / ↓ в полном экране (переключение каналов),
Enter, Esc (из архива в эфир / выход из полного экрана) и цифры (переход к каналу по номеру).

В полном экране Enter открывает список каналов поверх видео: ↑ / ↓, PgUp / PgDn, Home / End — выбор,
← / → — соседняя группа, Enter — смотреть, Esc — закрыть.

## Установка и готовая сборка

На странице [Releases](../../releases) доступны два варианта (устанавливать .NET или VLC не нужно):

1. **Установщик `WinTV-Setup-<версия>-win-x64.exe`** — устанавливает приложение в `%LocalAppData%\Programs\WinTV` (без запроса прав администратора), создаёт ярлыки на Рабочем столе и в меню «Пуск», регистрирует приложение в списке установленных программ Windows.
2. **Портативный архив `WinTV-<версия>-win-x64.zip`** — распакуйте в любую папку и запустите `WinTV.exe`.

При первом запуске добавьте ссылку на свой плейлист в настройках.
Настройки, кэш плейлистов, программы передач и логотипов хранятся в `%LocalAppData%\WinTV`.

## Сборка из исходников

Нужен .NET 8 SDK.

```bash
cd WinTV
dotnet build -c Release
```

Готовый `WinTV.exe` будет в `WinTV/bin/Release/net8.0-windows/`.

### Релиз

```powershell
.\publish.ps1
```

Скрипт публикует self-contained сборку для win-x64 (только 64-битная LibVLC) в `publish\WinTV`,
пакует портативный архив `publish\WinTV-<версия>-win-x64.zip` и собирает однофайловый установщик `publish\WinTV-Setup-<версия>-win-x64.exe`.
Версия берётся из `<Version>` в `WinTV/WinTV.csproj`.
Загрузить релиз на GitHub Releases:

```bash
gh release create v1.0.0 publish/WinTV-Setup-1.0.0-win-x64.exe publish/WinTV-1.0.0-win-x64.zip --title "WinTV 1.0.0" --notes "..."
```
